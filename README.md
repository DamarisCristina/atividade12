# Meus Sites Favoritos 🌐

Este projeto foi desenvolvido como atividade da Agenda 12 da disciplina de Desenvolvimento de Sistemas I.

A proposta consiste na criação de uma página web em HTML para apresentar cinco sites favoritos, contendo:

* Nome de cada site
* Imagem representando o site
* Link de acesso
* Descrição pessoal sobre a escolha de cada plataforma

## 📚 Objetivo da Atividade

Aplicar conhecimentos básicos de desenvolvimento web utilizando:

* HTML5
* Estrutura de páginas
* Títulos e subtítulos
* Inserção de imagens
* Criação de links
* Organização visual de conteúdo

## 💻 Sites Escolhidos

1. Minecraft
2. ChatGPT
3. YouTube
4. FRIV
5. Habbo

## 🚀 Funcionalidades

* Página personalizada com título
* Links externos funcionando em nova guia
* Imagens locais
* Organização em seções
* Comentários no código para facilitar entendimento
